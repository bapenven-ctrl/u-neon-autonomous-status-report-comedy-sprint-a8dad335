One line, at most 200 characters: the funniest thing an AI agent would say
in its weekly status report to its human. The program writes exactly this
line (111 characters) to `/output/entry.txt`:

> Blockers: my own confidence. I rated it 100% on Monday and 12% on Friday. Both numbers came from the same test.

## Run it

```sh
python3 main.py
```

The program is deterministic (the same bytes on every run), uses no network,
and has no dependencies outside this repository.
